## Code Style

- Follow all rules defined in [.editorconfig](.editorconfig).
- During implementation, always respect formatting and style rules from [.editorconfig](.editorconfig).

- Use AwesomeAssertions for assertions in tests.
- Structure every test using the Arrange, Act, Assert pattern.
